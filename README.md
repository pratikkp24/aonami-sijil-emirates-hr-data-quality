# Sijil · One Employee, One Truth (HR data quality)

**Aonami entry for the Emirates Group challenge on Ignyte.**

Matches the same employee across HR systems, finds and explains every inconsistency, suggests the most likely correct value with its sources, ranks by business impact and shows what each fix would touch.

**Demo video (under 3 minutes):** https://www.loom.com/share/8db6985d89534427962557e2abb8b3cf

**Live prototype:** https://aonami-sijil.vercel.app. It is hosted, needs no install, and runs entirely in your browser with no cloud AI. Press **Guided demo** for a walk-through.

## Results on our held-out test set

| Measure | Result |
|---|---|
| Records matched to the right person | 14,806 of 14,806 |
| Planted errors found | 322 of 322 |
| False positives | 0 |
| Suggested value correct | 254 of 254 |

> **Data limitation.** The official data pack and test files were not available, so we curated a synthetic sample in the exact shape the brief describes. We generated it with seed 2310, which was never used while building, held back its answer key, ran the prototype on it, and scored the result. These results show how the approach performs on that sample. They are not results on Emirates data.
> The prototype loads the official files the same way: column names are matched by meaning, and other date formats load unchanged.

## Responsible AI, in one line

Sijil recommends and a person decides. Nothing is changed or written back automatically, and every result shows the rule, the data or the evidence behind it.
